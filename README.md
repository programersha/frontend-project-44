### Описание проекта
<Brain Games (Игры разума)> 
- это консольное приложение с набором математических игр.
В каждой игре пользователю предлагается ответить на несколько вопросов, если все ответы верны - он побеждает, иначе игра заканчивается.

В проект включает в себя 5 игр:

1. Проверка числа на чётность
2. Калькулятор
3. Нахождение наибольшего общего делителя (НОД)
4. Арифметическая прогрессия
5. Проверка числа на простоту

### Минимальные требования
Для запуска проекта необходимы: 
- Node.js версии 14 и выше
- npm

### Установка и запуск
1. Клонировать репозиторий:  
    git clone https://github.com/programersha/frontend-project-44.git
2. Перейти в папку проекта:  
    cd frontend-project-44
3. Установить зависимости:  
    npm install

После установки будут доступны команды для запуска игр:
- brain-even        # Проверка на чётность
- brain-calc        # Калькулятор
- brain-gcd         # НОД
- brain-progression # Арифметическая прогрессия 
- brain-prime       # Простое ли число
